## Maszyna wirtualna (JVM) ##
- ELI5: To taki wirtualny komputer w komputerze. Możesz w nim uruchamiać programy napisane w Javie, niezależnie od systemu operacyjnego.  
- Definicja Java: JVM interpretuje i wykonuje pliki .class wygenerowane przez kompilator Javy, zapewniając niezależność platformową.

## Kompilator Javy (javac) ##
- ELI5: Tłumaczy to, co napisałeś w Javie, na język zrozumiały dla wirtualnego komputera.  
- Definicja Java: Program javac przekształca pliki .java w pliki .class zawierające bytecode, który może wykonać JVM.

## IDE (IntelliJ) ##
- ELI5: To magiczne pudełko z narzędziami, które pomaga pisać kod szybciej i bez błędów.  
- Definicja Java: Zintegrowane środowisko programistyczne wspierające edycję kodu, kompilację, uruchamianie programów i integrację z narzędziami typu Maven, Gradle i Git.

## Maven ##
- ELI5: Pomaga trzymać wszystkie części projektu w porządku i budować program jednym kliknięciem.  
- Definicja Java: Narzędzie do automatyzacji budowania projektów Java, zarządzania zależnościami, kompilacją i strukturą projektu.

## Pakiet (package) ##
- ELI5: To jak pudełko, w którym trzymasz powiązane klasy.  
- Definicja Java: Deklaracja grupująca klasy w logiczne jednostki w projekcie, ułatwiająca organizację kodu.

## Metoda main ##
- ELI5: To drzwi wejściowe do programu — komputer zaczyna stąd.  
- Definicja Java: Każdy program Java uruchamia się od metody 
``` public static void main(String[] args) ```

## Git ##
- ELI5: To magiczna pamięć, która pamięta każdą zmianę w kodzie i pozwala dzielić się nim z innymi.  
- Definicja Java: System kontroli wersji umożliwiający śledzenie zmian w projekcie i współpracę zespołową.

## Projekt Mavenowy ##
- ELI5: To pudełko z wieloma częściami: instrukcje, klasy, pakiety, które razem tworzą program.  
- Definicja Java: Struktura projektu zgodna z konwencją Maven: src/main/java dla kodu, src/test/java dla testów, plik pom.xml do zarządzania zależnościami i budowaniem.
