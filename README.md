# Moduł 2: Kontynuacja podstaw Javy

W tym module kontynuujemy naukę podstaw Javy. Skupimy się na fundamentach języka, które pozwolą Ci pisać własny kod i lepiej rozumieć działanie programu. Każdy temat ma osobny plik README z opisem, przykładami do wklejenia do klasy **Playground** oraz ćwiczeniami. Dodatkowo przygotowaliśmy pliki z gotowymi rozwiązaniami, które można sprawdzić lub przekleić, żeby zobaczyć efekt działania kodu.

## Struktura modułu

1. **Zmienne i typy danych** – opis typów prostych i referencyjnych, tworzenia i inicjalizacji zmiennych, przykłady użycia, ćwiczenia.
    - [readme/I-zmienne_i_typy_danych.md](readme/I-zmienne_i_typy_danych.md)
    - [readme/I-zmienne_i_typy_danych-cwiczenia.md](readme/I-zmienne_i_typy_danych-cwiczenia.md)

2. **Operatory** – arytmetyczne, logiczne, relacyjne, przypisania.
    - [readme/II-operatory.md](readme/II-operatory.md)
    - [readme/II-operatory-cwiczenia.md](readme/II-operatory-cwiczenia.md)

3. **Instrukcje warunkowe** – if, if-else, switch.
    - [readme/III-instrukcje_warunkowe.md](readme/instrukcje_warunkowe.md)
    - [readme/III-instrukcje_warunkowe-cwiczenia.md](readme/instrukcje_warunkowe-cwiczenia.md)

4. **Pętle** – for, while, do-while, iterowanie po tablicach.
    - [readme/IV-petle.md](readme/pekle.md)
    - [readme/IV-pet le-cwiczenia.md](readme/pekle-cwiczenia.md)

5. **Importy i pakiety**
    - [readme/V-importy-i-pakiety.md](readme/V-importy-i-pakiety.md)

## Jak pracować z tym modułem

- Każdy temat ma własny plik README z opisem i przykładami.
- W folderze **src/main/java** znajduje się klasa `io.udlbu.Main` z metodą `main`, w której będziemy wklejać przykłady.
- Ćwiczenia i gotowe rozwiązania w plikach z rozszerzeniem `-cwiczenia.md`.
- Każdy temat można przerabiać niezależnie, ale zalecamy zachowanie kolejności, aby lepiej zrozumieć zależności między elementami Javy.
- Gdy nie rozumiesz danego polecenia, wyjaśnienia, kodu - używaj ChatGPT lub alternatywnych narzędzi (traktuj to narzędzie nie jako `copy paste` ale Twój osobisty asystent 24/7)
